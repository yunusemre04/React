# 🎓 CourseAPP

A course listing application built with React and Vite as part of a structured React learning journey.

## 📖 About

CourseAPP is a front-end application that displays and organizes courses using a component-based React architecture. It focuses on core React concepts such as props, component composition, and UI rendering.

## ✨ Features

- 📚 Browse and list available courses
- 🧩 Reusable component-based architecture
- ⚡ Fast development experience with Vite + HMR
- 🎨 Clean and responsive UI

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start the development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

# ⚛️ React Learning Journey

A structured collection of React exercises and projects built while learning React from the ground up — covering core concepts, state management, routing, TypeScript, form handling, UI libraries, and full mini-applications.

---

## 📁 Repository Structure

```
React/
├── R1_Beginning/         # React basics & JSX
├── R2_Props/             # Props & component communication
├── R3_useState/          # State management with useState hook
├── R4_API/               # Fetching data from APIs
├── R5_Redux/             # Global state management with Redux
├── R6_Rooter/            # Client-side routing with React Router
├── R7_Typescript/        # React with TypeScript
├── R8_Formik/            # Form management with Formik
├── R9_MaterialUI/        # UI components with Material UI
├── R10_MaterialUI2/      # Advanced Material UI usage
├── Project1_CourseAPP/   # 🎓 Full Project: Course Listing App
├── Project2_ToDoAPP/     # ✅ Full Project: To-Do App
└── Project3_CommerceAPP/ # 🛒 Full Project: E-Commerce App
```

---

## 📚 Topics Covered

| Folder | Topic |
|---|---|
| `R1_Beginning` | JSX, functional components, rendering |
| `R2_Props` | Passing data between components via props |
| `R3_useState` | Managing local component state |
| `R4_API` | Fetching & displaying data with `useEffect` + `fetch`/`axios` |
| `R5_Redux` | Redux Toolkit, slices, store, dispatching actions |
| `R6_Rooter` | React Router DOM, nested routes, navigation |
| `R7_Typescript` | Type-safe React components with TypeScript |
| `R8_Formik` | Form handling, validation schemas with Formik & Yup |
| `R9_MaterialUI` | MUI components, theming, layout |
| `R10_MaterialUI2` | Advanced MUI: data grids, dialogs, custom themes |

## 🚀 Projects

### 🎓 Project 1 — CourseAPP
> A course listing application that displays and filters available courses.

- Built with **React + Vite**
- Component-based architecture with reusable UI elements
- Dynamic course listing and filtering
- Styled with **Material UI**

📂 [View Project](./Project1_CourseAPP)

---

### ✅ Project 2 — ToDoAPP
> A task management application with full CRUD functionality.

- Built with **React + Vite**
- Add, edit, complete, and delete tasks
- Form management and validation powered by **Formik**
- Clean and responsive UI

📂 [View Project](./Project2_ToDoAPP)

---

### 🛒 Project 3 — CommerceAPP
> A front-end e-commerce application with product browsing and cart management.

- Built with **React + Vite + TypeScript**
- Type-safe component structure with **TypeScript**
- Product listing, detail pages, and cart functionality
- Styled with **Material UI**

📂 [View Project](./Project3_CommerceAPP)

## ⚡ Getting Started

Each folder is a standalone Vite project. To run any of them:

```bash
# Navigate to the project folder
cd Project1_CourseAPP   # or any other folder

# Install dependencies
npm install

# Start the development server
npm run dev
```
